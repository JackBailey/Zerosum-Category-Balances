# Zerosum Category Balances (ZCB)

A browser extension for Zerosum to manage category balances.

This means you can link categories to accounts, to make the most of interest rates, or keep ownership of someone's money to their own accounts.

## Install

Download [extension.zip](https://github.com/JackBailey/Zerosum-Category-Balances/releases/latest/download/extension.zip) and extract `extension.crx` from it. Then drag it into your browser at [chrome://extensions](chrome://extensions).

It will then auto-update from GitHub.

## Disclaimer

This is not afilliated with Zerosum in any way.
